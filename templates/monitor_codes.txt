Коды теста для расчёта мониторинга по типам заявок.
Хранятся в БД (order_categories.monitor_codes), правятся в админке
(Блюда → Типы заявок). Этот файл — справочник: откуда взялся каждый код.
Сиды: «Булочки» — миграция 00020, «Хлеб» — миграция 00021.

БУЛОЧКИ (Б)
17642 Тесто арбатское ПФ
17644 Тесто на кокроки п/ф
17650 Тесто Сдобное п/ф
19694 Тесто ржаное пресное ПФ

ХЛЕБ (Х)
21429 Тесто арбатское хлебники п/ф   — Бабушкин Пшеничный хлеб, Багет Особый, Батон Нарезной, Мини багет с кунжутом, Хлеб чесночный мал, Хлеб чесночный ржаной мал
17642 Тесто арбатское ПФ             — Багет Провансаль, Тандырная лепешка, Лепешка мини, Хлеб чесночный
21212 тесто на Чиабатту              — Чиабатта, Чиабатта с Чесноком
21192 тесто для лепешки с луком      — Лепешка с Луком

Примечания:
- 17642 (арбатское) используется обоими типами — это нормально: расчёт
  идёт по заявкам одного типа, задвоения нет.
- Классический хлеб (Бородино, Дарницкий, Пшеничный, Украинский,
  Бездрожжевой, Кукурузный, Здоровье, Отрубной, тостовый, Батон
  бездрожжевой, Твороженый, на кефире) по техкартам iiko замешивается
  напрямую из сырья, без ПФ «тесто» — по кодам теста он не считается.

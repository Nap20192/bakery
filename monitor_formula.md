# Формула расчета monitor

Monitor считает, сколько конкретного ингредиента или полуфабриката нужно для заказа.

Основная формула:

```text
итого_ингредиента =
Σ(
  количество_блюда_в_заказе
  *
  количество_ингредиента_в_техкарте
  /
  выход_готового_продукта_по_техкарте
)
```

В терминах базы:

```sql
required_amount =
order_items.quantity
* iiko_assembly_chart_items.amount_in
/ NULLIF(iiko_assembly_charts.assembled_amount, 0)
```

## Поля

`order_items.quantity` - количество блюда в заказе.

`iiko_assembly_chart_items.amount_in` - количество ингредиента по брутто, которое указано в техкарте.

`iiko_assembly_charts.assembled_amount` - выход готового продукта, на который рассчитана техкарта.

`package_count` в расчете monitor не используется. Это не количество порций и не норма ингредиента. По данным iiko это поле относится к упаковке/тарным единицам строки техкарты.

## Почему нужно делить на assembled_amount

В iiko техкарта не всегда рассчитана на 1 изделие. Она может быть рассчитана на 10, 20, 75 или другое количество готового продукта.

Поэтому норму на одно изделие нужно считать так:

```text
норма_на_1_изделие = amount_in / assembled_amount
```

Потом эта норма умножается на количество из заказа:

```text
нужно_ингредиента_для_позиции =
quantity_в_заказе * (amount_in / assembled_amount)
```

## Пример: техкарта на 1 изделие

```text
Пирог капустный
quantity в заказе = 3

В техкарте:
amount_in = 0.27 кг теста
assembled_amount = 1

норма на 1 = 0.27 / 1 = 0.27 кг
нужно = 3 * 0.27 = 0.81 кг
```

## Пример: техкарта не на 1 изделие

```text
Булочка
quantity в заказе = 15

В техкарте:
amount_in = 3 кг теста
assembled_amount = 30 булочек

норма на 1 = 3 / 30 = 0.1 кг
нужно = 15 * 0.1 = 1.5 кг
```

## Правильная модель для отчета вхождения

Для точного и быстрого monitor лучше хранить нормализованную таблицу вхождения ингредиентов в блюда:

```text
ingredient_product_id
dish_product_id
ingredient_code
dish_code
amount_in_per_one
unit
date_from
date_to
source
```

Где:

```text
amount_in_per_one = amount_in / assembled_amount
```

Тогда monitor считается без повторного разбора техкарт:

```text
итого = quantity_блюда * amount_in_per_one
```
